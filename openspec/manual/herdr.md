# Herdr 終端工作區面板

在 Herdr 0.1.13 以上的終端工作區中，Speclink mod 提供停靠右欄與浮動面板，直接跟隨目前焦點終端所在 space 的專案狀態。資料沿用既有的 CLI 查詢與命令，不建立第二份真相；此整合只提供來源與安裝指引，不會自動修改你的 Herdr 或 Claude Code 設定。

## 面板跟隨工作區與資料狀態

- **停靠右欄與浮動面板**：停靠開關由每個 space 各自記憶（未記錄時預設開啟）；在非停靠版面可使用同一快捷鍵開關浮動面板。切換不同 space 時，面板會切換為對應專案的資料並恢復該 space 的開關狀態。
- **顯示內容**：呈現提案中、進行中、已就緒的變更、討論與已轉出討論，並顯示波次、阻擋對象、任務進度、worktree 與 review／verify 的章狀態。未轉完工作的已轉出討論會留在可繼續轉出的討論群組。
- **失敗處理**：CLI 查詢失敗時面板會顯示錯誤訊息，不會把失敗當成空專案。

## 技能推薦與送達

每列變更會依階段、任務進度、蓋章狀態、worktree 與待重新反映（drift）狀態建議下一步技能，展開鈕則列出其他適用技能：

- 程式任務完成且仍有 worktree 時，優先建議 `worktree-merge`。
- 合併後兩站尚未有效蓋章時建議 `quality`；已就緒且兩站有效蓋章時建議 `archive+commit`。
- 待重新反映時建議 `ingest`。
- 執行 `archive+commit` 時依序送出封存與提交意圖，一次只排一份。面板不會繞過 CLI 的安全驗收、認證、revision 或封存守門；被拒絕時不會自動加入旁路旗標或跳過失敗步驟。

送達技能時，面板會依已確認的 Agent 標籤、worktree 與 Claude Code 回報決定目標。若對應 Agent 正在等待回答，面板不會把技能當成回答送入；沒有合適目標時則依技能條件開新分頁或顯示不可用原因。

## 開工與技能選單

- **開工**：在目前 space 開新 Agent；若工作區開啟 `worktree` 政策，會先讓你選擇 `apply-with-worktree` 或直接 `apply`。
- **頂端技能鈕與快捷鍵**：開啟技能選單，僅列出符合條件的變更或討論，可開新分頁或一次放入輸入框；適用時可多選（但 `archive+commit` 不允許多選）。
- **列上附加鈕**：只把名稱放入目前輸入框而不送出命令；無可用 Agent 或 Agent 正等回答時停用。

## Agent 追蹤與側欄呈現

- 變更的 Agent 比對依 `speclink.change`、worktree 路徑、`speclink.focus` 的順序辨識；討論僅以 `speclink.discussion` 標籤辨識，不會因文字提及名稱就誤判為工作者。
- 面板區分做事中、閒置、完成與等待回答四種狀態，點擊工作者可跳轉過去；閒置 Agent 不會無故阻擋新工作。
- 停靠版面的 Spaces 列依階段顯示數量；Agents 清單可依 space 與狀態分組、呈現階段與進度，並可切回原排序。已有獨立分頁的 Agent 不會重複列在父 Agent 下。

## 桌面導航與初始化提示

- 點擊變更或討論列會以 `speclink://` 網址開啟對應的桌面 app 詳情頁（細節見[用 speclink 網址開啟畫面](desktop-deep-link.md)），波次或路線圖鈕開啟路線圖，Logo 則切換到目前專案看板（非本機 space 或未初始化時僅喚起 app）。
- 只有明確判定尚未初始化時才顯示初始化提示卡，點擊後在該專案新分頁執行 `speclink init` 與原互動工具選擇。若遇到找不到 CLI、壞設定（`.speclink.yaml` 解析錯誤）、離線或認證失效，面板會直接顯示錯誤，不會誤判為未初始化或自動覆寫設定。

## 系統語言與安裝邊界

面板、技能選單與整合內建畫面跟隨系統語言（偵測為 `zh`／`Chinese`／`中文` 時顯示繁體中文，其餘包含日文與未設定時顯示英文），不隨工作流設定的 `locale` 改變。翻譯不會改動檔名、差異內容或未知字串。
