## ADDED Requirements

### Requirement: 看板日期、建立者與任務摘要

桌面 SHALL 以共同的本地日曆日規則呈現看板與詳情相對時間，午夜刷新；建立者依 ID 分組，沒有 ID 時依名稱回退。變更全數勾完且有就緒日才顯示該日期。任務列 SHALL 支援繁中、日文、英文驗證標記。

#### Scenario: 時間和身分不同
- **WHEN** 本地時間剛過午夜，同名的兩名建立者各有一個 ID，其中一人曾改名
- **THEN** 前一日的更新顯示昨天；兩人有兩個篩選選項，改名的人只有一個

#### Scenario: 無新欄位的舊資料
- **WHEN** 舊 Server 的回應沒有識別、更新時間或就緒時間
- **THEN** 展現原有內容，依可用名稱篩選，缺失日期不顯示

### Requirement: 遠端專案狀態同步

桌面 SHALL 在啟動、回到前景及每 60 秒檢查遠端專案，即使尚未開啟。圖示列與系統匣共享狀態。被收回存取時保留當前可讀內容、禁止寫入，復權後自動恢復。

#### Scenario: 未開專案的連線失效
- **WHEN** 未點開的遠端專案連線失效後跑下一次檢查
- **THEN** 專案方塊與系統匣都顯示警示

#### Scenario: 恢復存取
- **WHEN** 已開專案的權限被收回後重新給予
- **THEN** 受限期間顯示警示且不能寫入，重新確認權限後恢復寫入

### Requirement: 繼續本機分頁跨重啟

同一資料夾有本機規格與遠端設定時，使用者選「繼續本機」後，桌面 SHALL 在切換分頁、重新開啟和背景檢查時沿用此分頁的本機選擇，先確認登記路徑仍是實際專案根。從「新增專案」再次開啟時仍依原流程顯示選擇。

#### Scenario: 恢復仍有效的本機分頁
- **WHEN** 有並存設定的本機分頁被保存在桌面，重新啟動後切回該分頁
- **THEN** 看板顯示原本機專案的資料，不再要求選擇；若原路徑已失效而只找到上層專案，顯示分頁錯誤，不讀上層資料
